# AWS EKS Infrastructure with Terraform and CI/CD

# Description
This project automates AWS infrastructure provisioning using Terraform and CI/CD pipeline.

# Technologies
- Terraform
- AWS (VPC, EKS, EC2, IAM)
- GitHub Actions

# Features
- Fully automated infrastructure deployment
- CI/CD pipeline triggers on push
- No hardcoded values (uses variables)
- Scalable and reusable architecture

# Infrastructure Includes
- VPC
- Public & Private Subnets
- Internet Gateway
- NAT Gateway
- Route Tables
- Security Groups
- EKS Cluster
- Node Group

# How to deploy

```bash
terraform init
terraform apply
